# 🗳️ ElPorvenir Opina - PWA de Encuestas Ciudadanas

Plataforma web desarrollada como Progressive Web App (PWA) orientada a la recolección, almacenamiento en tiempo real y análisis de encuestas ciudadanas sobre distintos partidos políticos[cite: 5, 9]. Diseñada para ofrecer una experiencia rápida, accesible y responsiva tanto en dispositivos móviles como de escritorio.

## 🚀 Enlace en Vivo (Demo)
Puedes explorar la aplicación en funcionamiento aquí: 
👉 [ElPorvenir Opina Live Demo](https://encuestas-porvenir.web.app/index.html)

## 🛠️ Tecnologías y Stack
* **Frontend:** JavaScript (ES6+), HTML5, CSS3[cite: 5]
* **Arquitectura Web:** Progressive Web App (PWA)[cite: 5, 9]
* **Base de Datos y Hosting:** Firebase (Firestore / Realtime Database) & Firebase Hosting[cite: 5]

## 📋 Características Principales
* **Recolección en Tiempo Real:** Envío y almacenamiento instantáneo de respuestas ciudadanas mediante Firebase[cite: 5].
* **Tecnología PWA:** Capacidad de funcionar de manera óptima como aplicación web progresiva, mejorando la accesibilidad para los usuarios[cite: 5, 9].
* **Visualización y Análisis:** Módulo para la visualización de resultados y tendencias de las preferencias electorales[cite: 9].
* **Diseño Responsivo:** Interfaz adaptada para una navegación fluida en smartphones, tablets y PCs.
