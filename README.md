# ElPorvenir Opina - PWA de Encuestas Ciudadanas

Plataforma web desarrollada como Progressive Web App (PWA) orientada a la recolección, almacenamiento en tiempo real y análisis de encuestas ciudadanas sobre distintos partidos políticos. Diseñada para ofrecer una experiencia rápida, accesible y responsiva tanto en dispositivos móviles como de escritorio.

## Enlace en Vivo (Demo)
Puedes explorar la aplicación en funcionamiento en el siguiente enlace: 
[ElPorvenir Opina Live Demo](https://encuestas-porvenir.web.app/index.html)

## Tecnologías y Stack
* Frontend: JavaScript (ES6+), HTML5, CSS3
* Arquitectura Web: Progressive Web App (PWA)
* Base de Datos y Hosting: Firebase (Firestore / Realtime Database) y Firebase Hosting

## Características Principales
* Recolección en Tiempo Real: Envío y almacenamiento instantáneo de respuestas ciudadanas mediante Firebase.
* Tecnología PWA: Capacidad de funcionar de manera óptima como aplicación web progresiva, mejorando la accesibilidad y el rendimiento para los usuarios.
* Visualización y Análisis: Módulo integrado para la visualización de resultados y tendencias de las preferencias electorales.
* Diseño Responsivo: Interfaz optimizada para una navegación fluida en teléfonos inteligentes, tabletas y computadoras.
