⬆️ Importar datos externos

Sube un archivo CSV con encuestas tomadas en papel, en Excel o descargadas de un Google Form. Cada fila se registrará como una encuesta.

📄 ¿Cómo preparo el CSV? (Google Forms, Excel, papel)
  • Excel: guarda la hoja como CSV UTF-8 (Archivo → Guardar como → CSV UTF-8).
  • Google Forms: abre las respuestas en Hojas de cálculo → Archivo → Descargar → CSV.
  • Papel: digiten los datos en Excel con las mismas columnas y guarden como CSV.
  • La primera fila debe tener los encabezados. Puedes usar nombres en español o en inglés.
  • Columnas opcionales: fecha, encuestador, id (para evitar duplicados al volver a importar).
  • Ejemplo de encabezados: sector,sexo,grupoEtario,candidatoFijo,decision,prioridad,cualidad,votoEspontaneo,fecha,encuestador
